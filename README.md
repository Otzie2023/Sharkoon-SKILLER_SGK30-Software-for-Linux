# Sharkoon-SKILLER_SGK30-Software-for-Linux
The Sharkoon SKILLER_SGK30  only has offical Windwos Support. Here I have developed software that can be used to control the keyboard lighting under Linux as well.

use (compulsory arguments):
sudo python3 sgk30_json_to_keyboard.py --json "Liçtmuster.json" --frame 0 --slow

Instead of ‘Liçtmuster.json’, a different pattern can be used.
